# Runvoid VS Code Extension

Official Visual Studio Code extension for the **Runvoid** programming language.

## Features

- **Syntax Highlighting**: Full syntax highlighting for Runvoid keywords, directives, colors, strings, and interpolated expressions `{...}`.
- **Bracket Matching & Auto-Closing**: Automatic pair closing for braces, parentheses, brackets, and quotes.
- **Auto-Indentation**: Automatic 4-space indentation for blocks, actions, loops, and window/screen UI definitions.
- **Code Folding**: Supports brace-delimited code folding.

## Installation

1. Copy or symlink this folder to your VS Code extensions directory:
   ```bash
   cp -r editors/vscode ~/.vscode/extensions/runvoid-vscode
   ```
2. Reload VS Code (`Developer: Reload Window` in Command Palette).
3. Any file with extension `.rv` will automatically have Runvoid language syntax highlighting and features enabled!

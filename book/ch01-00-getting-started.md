# 1. Getting Started

Let's begin your journey with Runvoid! 

In this opening chapter, you will take your first concrete steps into the Runvoid ecosystem. You will install the compiler toolchain, write and dissect your first native program, and learn how to wield the unified command-line toolchain.

Specifically, this chapter covers:

* **1.1 Installation & System Requirements:** How to install the Runvoid compiler, assembler (`nasm`), and C runtime linkers on **Linux** (using `install.sh` and native package managers) and **Windows** (using PowerShell `install.ps1` and CMD `install.bat`), plus cross-compilation toolchains.
* **1.2 Hello, World!:** Writing your first program, understanding the difference between compilation and execution, and inspecting the generated x86_64 assembly output.
* **1.3 The Compiler & CLI Tooling:** Navigating the `runvoid` command-line interface—running programs directly, compiling release binaries, formatting code, running test suites, launching interactive REPL sessions, and using watch mode.

Whether you are running an Arch Linux workstation, an Ubuntu server, or a Windows 11 development laptop, Runvoid is built to feel right at home. Let’s get started!

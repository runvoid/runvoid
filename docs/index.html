Why Runvoid?

Engineered for Beginners. Built for Systems.

💬

Conversational English Syntax

Write code that reads naturally: say, remember, repeat 5 times, for every item in backpack, if file exists.

⚡

Pure x86_64 NASM Compiler

Translates code directly into handwritten-quality assembly. Zero bytecode interpreters or bulky garbage runtimes.

📦

Ultra-Lightweight 15 KB Binaries

Compiles into standalone static Linux ELF executables that run instantly on any machine with zero installation.

🕹️

Hardware 2D Canvas & Desktop GUI

Build arcade games and native windowed tools with hardware acceleration out of the box.

🧵

POSIX Multithreading & Atomics

Spawn OS threads with shared memory and hardware-locked CPU atomic operations (lock add).

🛠️

Full Developer Ecosystem

Includes built-in code formatter (runvoid fmt), VS Code extension, template generator, and interactive cheat sheet.

Quick Setup

Install in Seconds

Runvoid runs on any Linux x86_64 distribution with GCC and NASM.

sudo pacman -S rust cargo nasm gcc libx11

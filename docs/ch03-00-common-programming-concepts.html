The Runvoid Programming Language

3. Common Programming Concepts

This chapter covers concepts that appear in almost every programming language and explores how they work in Runvoid. Many programming languages share foundational ideas—variables, data types, function calls, and control flow. None of these concepts are entirely foreign, but Runvoid expresses them through a conversational, human-centric philosophy while guaranteeing zero-overhead compilation to native x86_64 assembly.

In this chapter, you will learn about:

  • 3.1 Variables and Mutability: Declaring state with remember, reassigning values, scoping rules, stack allocation, and comments.
  • 3.2 Data Types & Expressions: Working with 64-bit integers, floating-point numbers, booleans, strings, string interpolation, and type inference.
  • 3.3 Functions & Actions: Defining reusable subroutines with action, passing parameters, returning values with give, recursive actions, and calling conventions.
  • 3.4 Control Flow: Branching conditionally with if, otherwise if, and otherwise, fixed-iteration loops with repeat N times, condition-driven loops with while, walking sequences with for every, and controlling loop execution with stop and skip.

Mastering these core concepts provides the foundation for building anything from command-line utilities to interactive games and systems daemons.

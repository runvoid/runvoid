# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

---

## Reporting a Vulnerability

The Runvoid team takes security issues seriously. If you believe you have found a security vulnerability in the compiler, runtime, or installer:

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories or by emailing the project maintainers.
3. Include detailed steps to reproduce the issue, along with a minimal reproducible `.rv` code sample.
4. Allow reasonable time for the maintainers to review, reproduce, and patch the issue before any public disclosure.

Thank you for helping keep the Runvoid ecosystem safe!
